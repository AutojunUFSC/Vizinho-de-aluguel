{# ===== Acessibilidade ===== #}

Acessibilidade

A plataforma segue as diretrizes WCAG 2.1 nível AA e oferece os seguintes recursos:

  • Alto contraste — . Inverte a paleta para fundo escuro com texto luminoso, sombras desativadas e bordas reforçadas. Sua preferência fica salva no navegador.
  • Mapa do site — esta página, lista hierárquica de todas as URLs do sistema, otimizada para leitores de tela.
  • Navegação por teclado — todas as interações são acessíveis via Tab/Enter/Espaço, com indicador de foco amarelo visível.
  • Pular para o conteúdo — link de skip-navigation aparece ao primeiro Tab, levando direto à área principal de cada página.
  • Movimento reduzido — animações são respeitam a preferência do sistema (prefers-reduced-motion).
  • Texto escalável — interface se adapta a aumento de fonte do navegador (Ctrl + +).
