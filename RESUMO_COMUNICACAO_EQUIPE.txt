📋 RESUMO DA REFATORAÇÃO BACKEND - VIZINHO DE ALUGUEL

O projeto foi refatorado para alinhar-se com a arquitetura especificada nos documentos base. O backend estava construído com Django REST Framework (API REST + serializers + JWT), mas a especificação define uma aplicação Django Templates pura (HTML renderizado no servidor + autenticação por sessão). Abaixo resumo das mudanças:

🗑️ O QUE FOI REMOVIDO:
- Django REST Framework (DRF) completamente
- Todos os serializers dos apps accounts, services e auctions
- Sistema de permissões DRF (permissions.py)
- Autenticação JWT
- Endpoints de API REST

Motivo: DRF foi criado para servir APIs a clientes externos (apps mobile, frontends SPA desacoplados). Neste projeto, o backend renderiza HTML diretamente para o browser. Manter DRF seria manter complexidade e dependências desnecessárias.

✨ O QUE FOI CRIADO:
1. Django Forms nativas para validação e salvamento:
   - LoginForm, CitizenRegisterForm, MEIRegisterForm, UserProfileForm, AddressForm
   - ServiceRequestForm, ServiceRequestMediaForm
   - BidForm, OrderCancelForm, ReviewForm

2. Decorators customizados de controle de acesso:
   - @citizen_required, @mei_required, @admin_required
   - Substituem o sistema de permissões DRF

3. Views renderizando templates HTML:
   - Accounts: login, cadastro, dashboards, perfis públicos, CRUD endereços
   - Services: lista categorias, CRUD solicitações, feed, adjudicação de bids
   - Auctions: gerenciar inscrições em categorias, criar/editar/retirar lances
   - Orders: detalhe, iniciar, concluir, confirmar, cancelar ordens
   - Reviews: criar avaliação, listar minhas avaliações, recalcular ratings via signals

4. Dois novos apps criados do zero:
   - apps/reviews: model Review, forms, views, signals (recalcula rating_avg), admin
   - apps/admin_panel: dashboard admin, verificação MEI, gerenciamento usuários/ordens

5. Configurações de infraestrutura:
   - core/settings.py reescrito: PostgreSQL, python-decouple, MEDIA_ROOT/URL, locale pt-br
   - core/urls.py atualizado: removidas rotas API, incluídos todos os 6 apps
   - requirements.txt corrigido: UTF-16 → UTF-8, adicionado psycopg2-binary, python-decouple
   - .env template criado para desenvolvimento local

📊 ESTATÍSTICAS:
- 3 serializers deletados (accounts, services, auctions)
- 6 novas Django Forms criadas
- 20+ views reescritas/criadas
- 2 novos apps criados (reviews, admin_panel)
- 8 novos urls.py/forms.py criados
- 1 arquivo de configuração corrigido

🎯 POR QUÊ ESSA MUDANÇA:
A refatoração elimina o mismatch entre o que foi implementado (API REST) e o que foi especificado (site tradicional Django). Resultado: código mais simples, menos dependências, melhor performance (sem serialização JSON desnecessária), e fluxo mais direto (request → validate → render template → HTML).

⚙️ PRÓXIMAS AÇÕES:
1. PostgreSQL deve estar rodando localmente (ou ajustar .env)
2. pip install Pillow (para ImageField)
3. python manage.py makemigrations && migrate
4. python manage.py createsuperuser
5. Testar fluxos: cadastro, lances, ordens, avaliações
6. Verificar app ui/ (equipe frontend): precisa ter rotas básicas
7. Criar diretório static/ se não existir
